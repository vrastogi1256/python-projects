## 🎓 Usage Examples

### Quick Start
```python
from linkedin_automation_platform import LinkedInAutomationPlatform
from linkedin_automation_platform.modules.ai_content_creator import ContentType

# Initialize
platform = LinkedInAutomationPlatform(user_profile={
    "name": "John Doe",
    "industry": "Technology",
    "primary_goal": "BRAND_BUILDING"
})

# Generate content
content = platform.create_optimized_content(
    content_type=ContentType.TEXT_POST,
    topic="AI in Business"
)

# Schedule post
post = platform.schedule_post(content)

# View dashboard
dashboard = platform.get_comprehensive_dashboard()
```

### Full Automation
```python
# Run complete automation
summary = platform.run_full_automation(
    duration_days=7,
    posts_per_day=1,
    engagement_hours=4
)
```
